# Egypt locations

Source: Open Admin Data, Egypt Administrative Divisions Dataset.
https://github.com/open-admin-data/egypt-administrative-divisions

Pinned upstream revision: 76b47b22872288c0d8b0c757975980e6986945e8.
Downloaded 2026-11-18. Source declares its last update as 2026-09-08.

27 governorates and 365 second-level districts, including markaz and urban qism
records, bilingual Arabic/English. JSON files are unmodified upstream downloads.
No runtime network access. This is a community snapshot, not a guarantee of
current official administrative completeness. Refresh deliberately from upstream
and re-run the integrity tests when updating. Villages/shiyakhas are out of scope.
